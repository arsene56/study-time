# study-time
作业时光：自主规划，快乐成长

双端高保真原型：家长手机竖屏、孩子平板竖屏。
完整流程：建立家庭 → 添加多位家长与多名孩子 → 设置固定作息 → 扫码绑定孩子端 → 模拟照片识别 → 自动排期 → 孩子认领计划 → 计时执行与动态重排 → 周报点评 → 星星奖励与兑换。
家长端：多孩切换、作业录入、进度查看、重要通知、修改记录、周报和奖励审批。
孩子端：自主调序、任务计时、成果拍照、超时选择、休息引导、打卡特效、嘀嘀皮肤与奖励商店。
排序规则：“一次短热身 → 尽早攻坚 → 在完整任务边界切换 → 交替用眼负荷 → 轻任务收尾”，并用历史数据逐步校准。
用眼默认值：1–2 年级 20 分钟、3–4 年级 25 分钟、5–6 年级 30 分钟专注，之后默认休息 10 分钟；阅读、绘画也计入近距离用眼。规则参考教育部儿童青少年近视防控指引和国家卫健委近视防控核心知识，产品中会表述为“辅助养成健康用眼习惯”。
技术方案：Monorepo；家长端 Taro + React + TypeScript，孩子端 React + Vite PWA，共享模型、规则、设计体系和模拟服务。
本阶段不开发 Spring Boot 后端，但预留清晰的接口边界。
品牌：作业时光；Slogan“自主规划，快乐成长”；主色薄荷绿＋暖橙；原创陪伴机器人「嘀嘀」。
演示数据：由我设计一个两孩虚拟家庭，覆盖不同年级和学习节奏。
原型刷新后保留演示进度，并提供“一键重置演示”，方便反复体验。
