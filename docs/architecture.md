# 作业时光：原型与生产架构边界

当前交付是一套便于评审和用户测试的高保真 Web 原型，家长端位于 `/parent`，学生端（平板）位于 `/student`，首次家庭设置位于 `/onboarding`。两端共享本地模拟数据，因此任务排序、计时、打卡、超时决策、星星和审批状态会实时同步。

验证通过后的方案 A 生产形态：

- 家长微信小程序：Taro + React + TypeScript。
- 学生端：React + Vite PWA，保留平板竖屏大触点体验。
- 共享层：任务模型、排期规则、主题令牌、模拟数据和接口类型。
- 后端：Java 21 + Spring Boot；承接家庭、成员关系、多孩隔离、OCR/AI、排期、实时同步、通知、奖励和周报。

原有线上原型的 OCR、个性化估时、扫码绑定和通知仍为可点击的模拟体验，不会上传真实数据。`apps/parent-miniapp`、`apps/student-pwa` 与 Spring Boot 正式业务链路已加入可替换的 OCR Provider、腾讯云高精度通用文字识别适配、识别结果人工修订，以及按学生隔离的近期加权个性化估时。

阶段 7 后，正式业务链路的信任边界位于 Spring Boot：客户端只提交业务动作，成员身份由 Bearer 会话解析；家庭/学生对象归属、家长专属操作、学生本人操作和 WebSocket 订阅都由服务端校验。重要事件与已读状态写入 MySQL，WebSocket 仅负责提示双端刷新。作业图片经过大小、文件签名和服务端对象名校验后才写入 MinIO。当前固定会话仅用于本地演示，微信登录、一次性 WebSocket 票据、HTTPS/WSS 和精确生产域名白名单在上线前接入。
