# 作业时光：原型与生产架构边界

当前交付是一套便于评审和用户测试的高保真 Web 原型，家长端位于 `/parent`，孩子平板端位于 `/child`，首次家庭设置位于 `/onboarding`。两端共享本地模拟数据，因此任务排序、计时、打卡、超时决策、星星和审批状态会实时同步。

验证通过后的方案 A 生产形态：

- 家长微信小程序：Taro + React + TypeScript。
- 孩子平板端：React + Vite PWA，保留竖屏大触点体验。
- 共享层：任务模型、排期规则、主题令牌、模拟数据和接口类型。
- 后端：Java 21 + Spring Boot；承接家庭、成员关系、多孩隔离、OCR/AI、排期、实时同步、通知、奖励和周报。

原型阶段的 OCR、个性化估时、扫码绑定和通知均为可点击的模拟体验，不会上传真实数据。
